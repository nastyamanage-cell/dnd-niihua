# НИИХУА

**Научно Исследовательский Институт Хитроумной Алхимии**

Веб-сайт для рождественского приключения D&D.

## Структура

- `index.html` - Главная страница
- `institute.html` - Страница об институте (расы и отделы)
- `style.css` - Основные стили
- `institute.css` - Стили для страницы института
- `script.js` - JavaScript для главной страницы
- `institute.js` - JavaScript для страницы института

## Запуск локально

Откройте `index.html` в браузере или запустите локальный сервер:

```bash
python3 -m http.server 8000
```

Затем откройте http://localhost:8000

## Деплой на Vercel

```bash
vercel --prod
```
